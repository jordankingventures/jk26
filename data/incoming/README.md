# Global Charts-upload

Sleep hier het bestand `gc.json` in (github.com → deze map → Add file → Upload
files → Commit changes). De workflow "Verwerk Global Charts-upload" leest het
bestand in, vult `data/analysis_data.json` aan en haalt `gc.json` hierna zelf
weer weg. Elke keer dezelfde bestandsnaam gebruiken is prima.

Het bestand maak je in Safari met het snippet uit `scripts/gc_bookmarklet.js`.
